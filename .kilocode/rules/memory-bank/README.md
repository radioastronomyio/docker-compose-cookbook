# Memory Bank

Context files for AI agent continuity across sessions.

## Files

| File | Purpose | Update Frequency |
|------|---------|------------------|
| [brief.md](brief.md) | Foundational context - what is this project | Rarely |
| [product.md](product.md) | Why this exists, goals, outcomes | Occasionally |
| [context.md](context.md) | Current state, next steps, decisions | Every session |
| [architecture.md](architecture.md) | Structure, patterns, design decisions | When structure changes |
| [tech.md](tech.md) | Technologies, setup, constraints | When stack changes |
| [tasks.md](tasks.md) | Repetitive workflows and procedures | As workflows emerge |

## Usage

**Session Start:**
1. Load brief.md (foundational)
2. Load context.md (current state)
3. Reference other files as needed

**Session End:**
1. Update context.md with accomplishments and next steps
2. Update other files if relevant changes made
