# Docker Compose Cookbook Brief

The Docker Compose Cookbook is a curated collection of 100+ Docker Compose configurations for self-hosted services, organized into 14 categories and designed for home lab environments. Each recipe provides a standardized, tested starting point for deploying common infrastructure services including databases, monitoring tools, networking, CI/CD platforms, AI/ML tools, media servers, and productivity applications.

This project exists to reduce the friction of self-hosting by providing copy-and-deploy configurations with sensible defaults. Rather than researching Docker image configurations from scratch, users can clone a recipe, adjust environment variables, and have a working service in minutes. The cookbook format emphasizes consistency, documentation, and best practices across all recipes.

Key features:
- **100+ recipes** across 14 active categories
- **Three-file pattern:** README.md, docker-compose.yml, .env.example for every recipe
- **GPU-optimized AI/ML recipes** for local LLM inference and image generation
- **Interior README pattern** for discoverability and RAG optimization
- **Comprehensive database coverage** with 8 subcategories by data model

The primary users are home lab enthusiasts, DevOps practitioners learning containerization, AI/ML hobbyists running local models, and small teams seeking self-hosted alternatives to cloud services. The repository is maintained under the radioastronomyio organization and welcomes community contributions for new recipes and improvements to existing ones.
